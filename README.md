# 🐍 Snake Game

A classic **Snake Game** implemented in Python using the `turtle` graphics module.  
This project recreates the nostalgic arcade experience — simple, engaging, and built purely with Python logic and animation.

---

## 🎮 Game Overview

The player controls a snake that moves around the screen to eat food and grow longer.  
Each time the snake eats, its speed and length increase, making the game progressively challenging.  
The game ends when the snake collides with the wall or with itself.

---

## 🧠 Features

- 🕹️ Smooth snake movement and collision detection  
- 🍎 Randomly spawning food at new positions  
- 🧩 Increasing difficulty as the snake grows  
- 🧮 Real-time score tracking  
- 💀 Game Over screen with restart option  

---

## 🧰 Tech Stack

- **Language:** Python 🐍  
- **Library:** `turtle` (Standard Library)

No external dependencies required — works out of the box with Python 3.

---

## ⚙️ How to Run

1. Make sure you have Python installed (3.8 or higher).
2. Clone the repository or download the project files.
3. Run the main script:
    --bash
   main.py
